Technical documentation of my homelab journey.

Lab 01: Hardware Acquisition & Initial Diagnostic
Device: Dell Optiplex 7040 SFF. CPU Intel Core i5
Manufacture Date:09-07-2016 
(further specifications pending...) 

Source: Facebook Marketplace ($30).

Included: System unit and one C13 power cable.

Seller Claim: "Unit does not power on".

Initial Triage
Visual Inspection: Checked for physical damage to the chassis and ports.
Unit is in suprisingly good condition. few minor scuffs and a little dusty but otherwise fine.

Power Test: Verified the seller's claim using the provided cable.
no lights

Component Isolation: I realized my monitor uses the same C13 connector power cord as the PC so i swapped
them out to check if issue is hardware related. 

Findings: The PC powered on :O. The monitor did not power on with PC's cable

Verdict: Power cord is faulty
Solution: ordered new power cord ($2)
